회사 소개

제품에 담은 개발 기준

Jinosoft(지노소프트)는 정보를 보관하고 다시 찾는 과정에 집중합니다. 계정 정보와 생활 기록, 각 데이터의 쓰임에 맞춰 저장 방식과 화면을 설계합니다.

01

기기 내 데이터 보관

LockSheet는 서버 계정 없이 사용하며, 기기에 저장한 계정 정보를 암호화해 보호합니다.

02

날짜별 기록 관리

Beecabi는 반려동물의 일상과 병원, 지출 내역을 날짜별로 정리하고 검색할 수 있습니다.

03

백업과 내보내기

두 앱 모두 백업과 내보내기를 지원해 기기 변경이나 기록의 별도 보관에 대비할 수 있습니다.
