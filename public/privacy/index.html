JINOSOFT

개인정보처리방침

시행일: 2026년 11월 3일

Jinosoft(이하 “운영자”)는 jinosoft.com 홈페이지를 운영하며, 이용자의 개인정보를 필요한 범위에서 처리합니다. 이 방침은 이 홈페이지와 앱 소개 페이지에 적용됩니다. 모바일 앱 자체의 개인정보 처리 내용은 각 앱의 별도 안내를 따릅니다.

1. 처리하는 정보와 목적

이 홈페이지는 회원가입, 댓글, 결제 기능이나 문의 입력 양식을 제공하지 않습니다. 이용자가 이메일로 문의하면 답변과 후속 지원을 위해 이메일 주소와 문의 내용을 처리할 수 있습니다. 문의 처리가 끝나고 후속 지원을 위해 더 이상 필요하지 않으면 지체 없이 삭제합니다. 법령에 따라 보관해야 하는 경우에는 해당 기간을 따릅니다.

2. 접속 기록

이 홈페이지는 GitHub Pages를 통해 제공됩니다. GitHub는 GitHub Pages 방문자의 IP 주소를 보안 목적으로 기록·보관한다고 안내하고 있습니다. 이 정보의 수집과 보관은 호스팅 제공자인 GitHub의 정책과 운영에 따릅니다. 자세한 내용은 GitHub Pages 안내와 GitHub 개인정보처리방침을 확인해 주세요.

3. 쿠키 및 분석 도구

현재 이 홈페이지는 운영자가 설치한 광고, 방문자 분석 도구 또는 추적용 쿠키를 사용하지 않습니다. 다만 GitHub Pages 등 서비스 제공자가 사이트 제공과 보안을 위해 처리하는 기술 정보는 해당 제공자의 정책을 따릅니다. Google Play와 기술 블로그 등 외부 사이트로 이동하면 해당 사이트의 개인정보처리방침이 적용됩니다. 기술 블로그의 방침은 블로그 개인정보처리방침에서 확인할 수 있습니다.

4. 제3자 제공 및 처리 위탁

운영자는 이용자 정보를 판매하거나 자체적으로 제3자에게 제공하지 않습니다. 다만 홈페이지 호스팅을 제공하는 GitHub는 서비스 운영 과정에서 접속 정보를 처리할 수 있습니다. 이메일은 이용자가 사용하는 메일 서비스 제공자를 통해 전달됩니다.

5. 정보주체의 문의

개인정보 처리에 관한 문의는 아래 이메일로 보내 주세요.

support@jinosoft.com

6. 방침 변경

홈페이지 기능이나 개인정보 처리 방식이 변경되면 이 페이지를 업데이트하고 시행일을 표시합니다.

광고가 이 홈페이지에 추가되는 경우, 광고 제공자가 쿠키·웹 비콘·IP 주소 등으로 정보를 처리할 수 있다는 점을 포함해 이 방침을 갱신하겠습니다. 현재 광고는 게재하지 않습니다.
